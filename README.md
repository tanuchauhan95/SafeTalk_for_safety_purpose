---

## 📌 Project Description
SafeTalk is a smart women safety application designed to provide quick emergency assistance using modern technologies like voice recognition, GPS tracking, and encryption.

---

## 🎯 Features

- 🔴 SOS Button for instant emergency alert  
- 🎤 Voice Trigger ("HELP") for hands-free activation  
- 📍 Real-time location sharing using GPS  
- 📩 SMS alert to emergency contact  
- 🔐 Message Encryption for security  
- 🔓 Decryption included for demonstration  

---

## ⚙️ Technologies Used

- Java  
- Android Studio  
- Android SDK  
- GPS / Location Services  
- SMS Manager API  
- Speech Recognition API  
- Base64 Encryption  

---

## 🚀 How It Works

1. User clicks SOS button OR says "HELP"  
2. App detects emergency  
3. Location is fetched using GPS  
4. Message is encrypted  
5. SMS is sent with location and alert
